# Bansi Fashion — Industrial Production & Worker Management System

## 🚀 1-Click Launch (એક જ કમાન્ડથી બધું જ શરૂ કરો)

મુખ્ય `Bansi Fasion` ફોલ્ડરમાં ટર્મિનલ ખોલીને ફક્ત આ કમાન્ડ ચલાવો:

```bash
npm start
```

આ એક જ કમાન્ડથી:
1. 🚀 **Backend Server** (Port 5000) શરુ થશે.
2. 🍃 **MongoDB Connection** શરુ થશે.
3. 💻 **Frontend Web App** (`http://localhost:5173`) ઓપન થશે.

---

## 🛠️ ઉપલબ્ધ કમાન્ડ્સ (Commands):

| કમાન્ડ | વિગત |
|---|---|
| `npm start` | Backend Server + Frontend બંને એકસાથે ચાલુ કરશે |
| `npm run dev` | Backend Server + Frontend ચાલુ કરશે |
| `npm run dev:admin` | Backend + Admin Panel અલગ પોર્ટ પર ઓપન કરશે (`http://localhost:5173`) |
| `npm run dev:worker` | Backend + Worker Panel અલગ પોર્ટ પર ઓપન કરશે (`http://localhost:5174`) |
